---
title: Hide dependencies from synopkg
---

Ignore one or more dependencies so that synopkg does not inspect them.

### 1. Add an ignored version group

- Match 2 specific **packages** in the repo.
- Match only the **peerDependencies** in those packages.
- Add a **label** to document the decision/expectation.

```json title=".synopkgrc.json"
{
  "versionGroups": [
    {
      "label": "Nothing to see here, will fix soon",
      "packages": ["oops-moment", "workaround"],
      "dependencyTypes": ["peer"],
      "isIgnored": true
    }
  ]
}
```

With this configuration in place, synopkg will now completely ignore every dependency listed under `peerDependencies` in the two named packages `oops-moment` and `workaround` only.
