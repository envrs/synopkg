Synopkg searches the current directory for a:

- `.synopkgrc` file with no extension in JSON format
- `.synopkgrc` file with the extension `.json`, `.yaml`, `.yml`, `.js`, `.ts`, `.mjs`, or `.cjs`
- `synopkg.config.js`, `synopkg.config.ts`, `synopkg.config.mjs`, or `synopkg.config.cjs` file
- `config.synopkg` or `synopkg` property in `package.json`.

A custom name and location can be provided instead, but it must have a file extension:

```bash frame="none"
synopkg list --config ./config/synopkg.json
```

Your config file only needs to define values for those you want to change from the defaults.

## JSON

JSON is preferred as it is the fastest, without the overhead of calling out to Node.js and TypeScript.

```json title=".synopkgrc.json"
{
  "$schema": "./node_modules/synopkg/schema.json",
  "indent": "    "
}
```

## TypeScript

```ts title=".synopkgrc.ts"
export default {
  indent: "    ",
} satisfies import("synopkg").RcFile;
```

## JavaScript

```js title=".synopkgrc.cjs"
// @ts-check

/** @type {import("synopkg").RcFile} */
const config = {
  indent: "    ",
};

module.exports = config;
```
